## 5. Explicitly Declined & Out-of-Scope Architecture

The following technologies and features are strictly declined and excluded to preserve WWCF data privacy, local-first reliability, and ministry guidelines:
- **Gemini AI API Calls / LLM Chatbots**: Excluded; all recommendation, rotation, and harmonic analysis algorithms are pure deterministic TypeScript.
- **Firebase / Supabase Cloud Databases**: Excluded; LocalStorage is the sole local storage engine; Google OAuth 2.0 Web Client ID Option A provides user-controlled Google Drive backups without third-party cloud database dependency.
- **IndexedDB**: Excluded; unified on LocalStorage for reliability across web views and backup envelopes.
- **PWA Service Workers / Offline Workers**: Excluded; application runs as a clean Vite SPA.
- **Automated Test Runners (Vitest / Jest / Cypress)**: Excluded; verified via `compile_applet`, `lint_applet` (`tsc --noEmit`), and focused runtime HTTP/TS verification scripts.
- **Google Calendar / Gmail / Messaging API Scopes**: Excluded; manual clipboard Service Brief and printable rehearsal sheets are favored for direct distribution.
